# 🚀 MERN AI Chat App (Ollama + Qwen2.5:0.5B + PDF Chat)

A full-stack MERN application that integrates a local AI model using Ollama.  
This app supports:

- 💬 Normal AI Chat
- 📄 Chat with PDF (Ask questions from uploaded documents)

---

## 🧠 Tech Stack

### Frontend
- React.js
- Axios
- Tailwind CSS (optional)

### Backend
- Node.js
- Express.js

### Database
- MongoDB (Mongoose)

### AI & Processing
- Ollama (Local LLM)
- Qwen2.5:0.5B
- PDF Parser (pdf-parse / langchain optional)

---

## ✨ Features

### 💬 Normal Chat
- Ask anything to AI
- Fast local inference using Ollama
- Simple chat UI

### 📄 PDF Chat
- Upload PDF files
- Extract text from PDF
- Ask questions based on PDF content
- Context-aware answers
